## 📝 Descripción del Proyecto

**MenuExpress** es una solución web integral diseñada para la automatización y gestión fluida de cartas digitales, comandas y pedidos en establecimientos gastronómicos (restobares). El sistema optimiza la comunicación entre el personal de atención y la cocina, reduciendo tiempos de espera y centralizando el registro de ventas.

---

## ⚙️ Características Principales

- 🍽️ **Gestión de Menú y Categorías:** Registro, actualización y control de disponibilidad de platillos y bebidas en tiempo real.
- 📝 **Toma de Pedidos Digital:** Registro de comandas asociadas a mesas o clientes.
- 🗄️ **Persistencia de Datos:** Arquitectura mapeada con JPA/Hibernate hacia MySQL con integridad referencial.
- 🎨 **Interfaz Responsiva:** Pantallas adaptables para dispositivos móviles y tablets utilizando Thymeleaf y Bootstrap.

---

## 🏗️ Arquitectura y Tecnologías

El proyecto sigue una arquitectura por capas desacoplada (**Controller - Service - Repository - Model**):

- **Backend:** Java 17, Spring Boot, Spring Data JPA, Spring Validation.
- **Frontend / Vistas:** Thymeleaf, HTML5, CSS3, JavaScript, Bootstrap 5.
- **Base de Datos:** MySQL Server.
- **Herramientas:** Maven, Postman, Git.
